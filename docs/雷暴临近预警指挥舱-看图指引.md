## 一、屏幕上每个图形是什么（这张表就是"看不懂"的解药）

### 全国尺度 · 雷暴临近预警

| 看到的东西 | 它是什么 | 数据来源 |
|---|---|---|
| **彩色云团**（蓝绿黄橙红） | 雷达回波。颜色 = 组合反射率 dBZ，越红代表云越强 | 雷达 · 实测 |
| **白色小点**（密集簇状） | 闪电落点。正地闪偏黄、负地闪偏白、已拦截偏青 | 闪电定位 · 实测 |
| **四道同心圈 200/150/100/50 km** | 客户《防雷应急预案》里的四级预警阈值 | 预案阈值 |
| **从矿区向外扫的光带** | 雷达扫描。表示"系统正在盯着这个矿区"，每 4.6 秒扫一圈 | 交互提示 |
| **橙色虚线 + 箭头** | 雷暴移动方向与未来 30 分钟落区 | 雷达外推 · 模型预测 |
| **矿区圆环** | 环的颜色 = 当前预警等级（红/橙/黄/蓝对应 1/2/3/4 级） | 计算 |
| **矿区旁两行小字** | 上：`一级预警 · 距雷暴 45 km`；下：矿区名称 | 计算 |

### 场区尺度 · 保护范围孪生（点任意矿区进入）

| 看到的东西 | 它是什么 |
|---|---|
| **半透明圆 R39m** | 一支接闪杆的保护半径，按滚球法 `R = √(h(2D−h)) − √(h_x(2D−h_x))` 算出 |
| **向上的小竖线 + 圆点** | 接闪杆 |
| **方框** | SPD 浪涌保护器；外面那圈细线是它的有效保护距离 |
| **三条横线** | 主接地网（水平接地体） |
| **菱形** | 大气电场仪 / 雷电流记录仪等监测终端 |
| **红色脉冲圈 + 距杆 xxx m** | 该设备落在所有保护圈之外 —— 这就是要整改的点 |
| **黄线云→杆、青线杆→地网** | 雷电流路径：下行先导 + 泄流通道，旁边是电流读数 kA |
| **虚线方框** | 场区作业边界，右下角有 100 m 比例尺 |

## 二、预警分级口径（已按你的要求实现）

| 距离（雷暴边缘 → 矿区边界） | 等级 | 预案动作（界面显示原话） |
|---|---|---|
| ≤ 50 km | **一级预警** | 启动应急预案，必要时停产撤人 |
| ≤ 100 km | **二级预警** | 限制作业，值班加强，物资到位 |
| ≤ 150 km | **三级预警** | 核查防护装置，暂停高空作业 |
| ≤ 200 km | **四级预警** | 关注气象跟踪，正常作业 |
| > 200 km | 无预警 | 正常运行 |

预警梯子（50/100/150/200 四个小方块）常驻在左侧主指标下方，领导不用记阈值。

## 三、四个业务模块（对齐 V1）

底部胶囊切换，每个模块只开对应图层 —— 模块化本身就是最强的降噪：

| 模块 | 图层 | 回答 |
|---|---|---|
| **实时监测** | 省界 + 闪电点 | 现在哪里在打雷 |
| **热力分析** | + 雷达回波 | 云有多强、覆盖多大 |
| **移动轨迹** | + 雷暴矢量 + 输电通道 | 它往哪走、会不会压到线路 |
| **临近预警**（默认） | 省界 + 回波 + 闪电 + 四级距离圈 | 离我的矿区多远、该干什么 |

## 四、三分钟演示脚本

1. **打开就是临近预警。** 左上角 45 km 是全场区最近的一次雷暴距离。
2. **指左侧预警梯子**：50/100/150/200 —— 这是你们预案里的四个数，系统直接按它判级。
3. **指地图上那个正在被扫的矿区**：神东矿区，一级预警，距雷暴 45 km。等一圈扫描扫过去，说明系统在持续盯着它。
4. **指右侧清单**：按距离排序，神东 45 km 一级、粤东 51 km 二级、攀西 121 km 三级、六盘水 267 km 正常。一眼看出该先处理谁。
5. **点神东矿区** → 镜头俯冲进场区，屏幕换成保护范围图：三支 42 m 接闪杆的保护圈、圈外的两台设备标红。
6. **点左下角结论卡** → 空档诊断 + GB 50057 整改建议。
7. **底部切四个模块**，说明这套系统就是 V1 那四个模块的统一入口。

收尾一句：**"它不告诉你今天打了多少雷，它告诉你雷离你的矿区还有多少公里、现在该做什么。"**

## 五、实现口径（便于对接真实数据）

| 数据 | 现在（演示） | 接真实数据 |
|---|---|---|
| 雷达回波 | `data.ts` 按 4 个雷暴单体生成 dBZ 单元 | 雷达组合反射率接口（含经纬度、dBZ、移动矢量） |
| 闪电 | 按雷暴单体分布生成，幅值 ≤210 kA | 闪电定位接口 |
| 预警判级 | `warningFor()` 按客户四级阈值，从最紧的圈向外判 | 阈值可配置即可直接上线 |
| 保护范围 | `twin.ts` 滚球法逐点计算，留 1 m 工程余量 | 换真实杆高与设备坐标 |

**已自查**：`vue-tsc` 与 `vite build` 通过；预警分级、距离、保护判定均逐条在运行时核对过。
