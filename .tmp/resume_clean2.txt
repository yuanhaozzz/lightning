1. GitLab CI/CD 自动化部署 + 代码规范检测 
项目背景：
公司前端项目采用传统手动部署方式，发布流程繁琐，且团队代码风格不统一，导致测试环境频繁报错，影响迭代效率。
为什么这样做：
 手动部署效率低：每次上线需运维介入，耗时且易出错。 
代码质量参差不齐：团队成员编码习惯不同，ESLint 仅本地运
行，无法强制规范。 
我的方案:
自动化部署：基于 GitLab CI/CD 设计多环境（dev/test/prod）流水线，实现 代码提交 → 自动构建 → 部署测试 → 人工
审核 → 生产发布 全流程自动化。 
代码强校验：集成 ESLint + Prettier，结合 Husky 在 git commit 阶段拦截不规范代
码，并配置 GitLab Merge Request 卡点，未通过检测的代码禁止合入主干。 
带来的收益   部署效率提升    代码缺陷率
下降 40%：通过卡点机制，ESLint 错误在开发阶段即被拦截，测试阶段 Bug 数显著减少。

业务描述：
 提高营收 
运用技术：
react全家桶、webpack 
职责描述
：
开发9宫格、转盘、老虎机、活动等 
遇到问题：
 
    1. svga动画播放卡顿
             删减动画，使用序列帧，利用浏览器APIrequireAnimationFrame 播放动画，判断浏览器当不支持. 时，采用       
      setTimerout向下兼容。
    2. 原生事件比react事件先执行
            react采用事件代理，冒泡机制、17中绑定在传入的root上，减少内存消耗
            原生事件组织事件冒泡，则react事件无法触发
    3. hooks闭包问题
            一般使用浏览器API或者事件 都会遇到没有更新的问题，可放在fiber对象ref中
    4. memo缓存失效
            - 使用memo缓存组件
            - props上属性都必须缓存，只要有一个是新值，则缓存失效
