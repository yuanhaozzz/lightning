# 雷电数字战场 · V2 视觉 Demo

入口仍为 `/tianji-command`。本次仅修改当前目录，采用已有 Vue + Three.js 和本地中国 GeoJSON，不接入或修改真实业务接口。

## 第一阶段场景

默认进入态势视角，重点展示 **T06 → 神东矿区**：78 km、ETA 18 min、42 km/h、东北方向、Ⅱ 二级威胁。T01 / T03 / T05 作为其他活动目标。

首次打开自动构建约 5.3 秒：地图 → 扫描 → 雷暴逐个显现 → 编号识别 → 历史/预测航迹绘制 → 资产锁定 → 威胁走廊 → 距离与 ETA。完成后仅保留缓慢能量扰动、航迹粒子、资产心跳与少量雷击冲击波，可用底部状态旁的重播按钮再次观看。

地图采用深蓝黑、低对比行政边界、细网格和抽象纹理。程序化 shader 生成雷暴的外围光晕、扰动能量区和暖色核心；批量点云表现内部活动。距离圈为 50 / 100 / 150 / 200 km，按当前模拟距离只激活对应一层。取消原右侧雷暴列表，标签跟随空间位置。

## 已接通的演示交互

- 四种模式共用同一 renderer、相机和地图，切换时插值改变图层权重。
- 态势 / 全国视角、2D / 3D、缩放、平移、旋转和复位。
- 六个独立图层开关；默认显示 3 个重点煤矿，切换「全部煤矿」呈现当前演示数据中的 6 个点位并切至全国视角。普通点位不展开名称，当前关联煤矿始终可见。
- 点击云团本体或编号进入云团分析：基于未来 180 分钟轨迹扫过的圆形覆盖范围筛选煤矿，按精确首次影响时间选择目标，不再选择直线距离最近的煤矿。无命中时显示「当前轨迹范围内暂无受威胁煤矿」，仅保留向前预测轨迹与走廊，不绘制煤矿连线或资产防御圈。
- 云团锁定仅使用四角框、局部扫描弧、编号和呼吸高亮。50 / 100 / 150 / 200 km 防御圈始终以资产为中心；云团分析中只在实际受影响煤矿锁定后展开。
- 点击云团后的 2.7 秒分析：其他云团降亮 → 锁定 → 历史轨迹 → 运动矢量 → 预测轨迹 → 走廊 → 扫描煤矿 → 资产锁定 → 四层防御圈 → 威胁路径 → 方向粒子 → 距离、ETA 和危险等级。再次选择会中断并重启序列，分析期间暂停自动时间推进，减少目标漂移。
- 点击煤矿进入反向分析：镜头轻微聚焦，先展开防御圈，再用同一轨迹覆盖模型筛选会影响该矿的雷暴，按首次影响时间、距离等级、强度排序。排除近距离但轨迹错开的云团，也能识别当前在 200 km 外、未来会进入的目标。地图复位退出分析。
- 距离 / ETA / 危险等级以极简文字显示在预测路径中段；点击分析时收起左侧详情区，普通云团仅保留编号。走廊方向不向煤矿偏转，威胁路径沿预测轨迹到首次影响位置，再标出覆盖范围与资产的关系；移除大三角箭头。
- 13:32–16:32 的时间轴，14:32 为 NOW；位置平滑插值，航迹、走廊、事件时间窗口与距离圈随时间更新。
- 播放 / 暂停、1× / 2× / 4×、回到当前、未来 2 小时推演。启动构建完成后自动播放；1× 每秒推进 15 秒场景时间。云团沿轨迹缓慢移动，内部粒子按当前方向流动，轮廓轻微扰动与呼吸，历史能量残影、轨迹和位置标记逐渐衰减。
- 尊重 `prefers-reduced-motion`：直接呈现完成态势并关闭持续动效；页面隐藏时停止渲染与时间推进。
- Vue 仅承载少量 UI 标签；560 条模拟事件由单个 GPU 点云处理，雷击冲击波使用最多 8 个复用对象。卸载释放纹理、几何、材质、renderer、观察器和监听器。

## 数据边界

默认开场仍是**视觉脚本**：需求中的 `78 km / 42 km/h / 18 min` 不是恒速移动下相互推导的一组物理量，开场保留预置读数。**点击云团或煤矿后切换为计算结果**：显示距离为云团边缘到已命中资产的当前距离；ETA 为移动圆形覆盖范围首次碰到煤矿的时间，向上取整到分钟。使用连续最近接近点搜索与首次相交二分，避免离散采样漏掉短暂穿越；目标排序使用未取整的影响时间。预测窗口为未来 3 小时，路径错开、远离且未覆盖、窗口内未抵达的目标被排除；已覆盖时 ETA 为 0。因此点击 T06 后 ETA 会与开场的 18 分钟不同。

距离圈使用球面目的地算法；运动位置沿给定方向按速度推进。全国雷电总量是模拟概览值，地图仅绘制演示事件样本。「全部煤矿」仅指已有 6 个模拟矿区，并非全国真实煤矿数据库。圆形覆盖范围与能量外沿尚未经过雷达模型校准，所有计算仅用于演示。

## 文件

- `index.vue` / `weather.css`：指挥舱布局、交互和响应式样式。
- `commandDemo.ts`：独立 Demo 数据、阶段时序、读数和事件流。
- `commandAnalysis.ts`：沿轨迹的首次影响时间、双向威胁筛选、动态距离 / ETA 与分析时序。
- `commandScene.ts`：地图、shader 能量体、点云、航迹、走廊、防御圈和资源生命周期。
- `weather.ts`：沿用原地理算法与类型；原 `weatherScene.ts` / `focus.ts` 保留，但新页面不再引用。

## 验证

```sh
npm run build
node src/features/tianji-command/commandDemo.check.mjs
node tmp/tianji-weather-check.mjs
```

本轮按用户要求只执行编译与计算逻辑检查，浏览器画面验收由用户进行。计算检查覆盖近距离偏离轨迹、较远资产更早命中、预测期无目标、短暂穿越、已覆盖、煤矿反向筛选及 200 km 外接近目标。真实数据接入、全国海量数据 LOD 与雷达模型校准不属于本阶段。
