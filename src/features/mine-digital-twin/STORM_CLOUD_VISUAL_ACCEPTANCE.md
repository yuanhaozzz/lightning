# 雷暴云团与空间环境视觉验收

本轮只优化 `/mine-digital-twin` 的视觉。没有改动布局、GLB、设备 ID、Blender 脚本或其他业务路由，没有新增闪电、降雨、业务数据或自动巡航。

## 实现与文件

| 文件 | 内容 |
| --- | --- |
| `stormCloudState.ts` | 水平跨度、云底、云顶分别配置；保持原有时间轴、暂停和退出淡出逻辑 |
| `stormCloudDensity.ts` | 连续噪声形态、塔状云顶、平坦云底；一次烘焙密度和光照；计算有效密度轮廓及空白裁剪边界 |
| `stormCloud.ts` | 保留单体积盒 ray marching；RG 体积场、固定空间采样扰动消除条纹，光照恢复及资源释放 |
| `mineEnvironment.ts`（新增） | 园区外环地形、远山轮廓、渐变天空、距离雾和柔和云影；保留井口开孔及接地剖视 |
| `stormView.ts`（新增） | 按云团移动两端的有效轮廓固定构图；整体、地面仰视、斜俯视，适配竖屏 |
| `index.vue` | 接入现有渲染循环；底部“演示视角”入口；复用镜头动画并平滑插值 FOV；原始鸟瞰独立保留 |
| `stormCloud.check.mjs` | 云体形态、高度、时间轴、恢复及资源释放检查 |
| `stormVisual.check.mjs`（新增） | 多宽高比构图、园区占比、外围地形边界、剖视与资源释放检查 |

体积场水平尺寸为 310 × 220 米，X 跨度约为园区宽度的 2.1 倍。容器垂直范围为 58～154 米，有效密度的云底约 65.6 米。这是当前场景的视觉示意参数。

演示视角用整个移动范围一次拟合，不随云团逐帧追踪或缩放。开始/重播切到演示整体视角，退出平滑返回原始鸟瞰；手动拖动或键盘操作立即取消镜头过渡。地面视角允许仰视，普通视角保留原先的地面以上旋转限制。

## 验证

运行并通过：

```text
npm run build
node src/features/mine-digital-twin/stormCloud.check.mjs
node src/features/mine-digital-twin/stormVisual.check.mjs
node src/features/mine-digital-twin/stormDemo.check.mjs
node tmp/verify-mine-interaction.mjs
```

构图检查覆盖 1440×900、1920×1080、604×871、390×844。整体演示视角的园区宽度占桌面画面约 41%～44%；同时保留整个云团轮廓。地形网格全部位于原园区矩形之外。39 项既有建模/资源文件哈希一致。

浏览器实际检查记录：`tmp/mine-storm-visual-browser-check.json`。确认：

- 暂停冻结位置、透明度与演示时间；继续连续移动。
- 播放到约 30 秒时镜头位置保持不变，园区主要建筑仍可见。
- 云体及天空不参与业务拾取；点击井架可定位。
- 配电室屋顶隐藏后可通过 Raycaster 独立选中 `spd-lv-01`。
- 图层切换独立于云体，旋转操作保持有效。
- 恢复原始鸟瞰清除选择、恢复屋顶与图层。
- 退出初始透明度约 0.975，随后降到 0；主光、环境光和环境贴图强度精确恢复到 2.4 / 0.65 / 0.35。
- 重播返回初始云位置并重置时间及 run ID。
- 浏览器检查未发现控制台错误。

## 资源与性能

云体仍为 1 个绘制对象、12 个三角形、1 个材质、1 张 3D 纹理，最多 48 次射线采样。144×64×104 RG8 场为 1,916,928 字节（约 1.83 MiB）；没有增加透明粒子层。噪声和光照只在初始化烘焙，暂停后按需渲染。

外围环境最多增加 3 次绘制，地形 2,624 个三角形、1,476 个顶点，无新增图片纹理。

1440×900 桌面浏览器实测 90 帧：帧间隔中位数 **25.0 ms**（约 **40 FPS**），P95 **29.2 ms**；CPU 提交与标识布局中位数 **1.9 ms**。这些是整个场景和浏览器的观察值，不是单独 GPU 计时，也未达到恒定 60 FPS。固定空间采样扰动仍可能有轻微颗粒，这是轻量体积方案的画质取舍。

本轮已停止在视觉验收阶段。
