## 本轮交互

首次进入：全国态势 → 选择危险矿区 → 目标高亮 → 远景 / 中景 / 45° 最终构图 → 2.8 秒测距 → 自由交互。

- 镜头同时容纳完整云团范围与矿区，并预留 UI 位置；不存在危险目标时保持全国态势。
- 镜头按距离调整时长。拖动、滚轮、触控、切换目标、页面隐藏均停止旧序列；可跳过、重播。
- 云团边界到矿区的测距线渐进展开，依次显示距离、方向、速度和 ETA；选矿区会重新构图和测距。
- 地图云团、矿区标记和矿区下拉框均可选择目标。六个图层、四种模式与时间轴继续使用。
- 历史路径为实线，预测路径为虚线；时间轴支持拖动、暂停、1×/2×/4×、回到当前。
- `prefers-reduced-motion` 下跳过自动飞行与连续动效。资源随路由卸载清理。
- 点击底部状态栏的「重播演示」可重新体验整段镜头；它与时间轴左侧的播放按钮分别控制镜头演示和数据回放。
- 程序云团采用 Cesium 原生 `CloudCollection`，最多 48 个云团单元、三层示意高度；通过噪声切片和亮度缓慢变化表现流动，全国视角及低配置设备减少云团单元。
- 轨迹流动点遵循当前历史/预测路径。播放时间轴跨过所选雷暴的模拟雷击事件时，触发一次柔和雷击光效；暂停不会生成新的雷击，拖动时间轴不会补播全部事件。

## 数据与地理边界

所有雷暴、事件和矿区位置均为演示数据。沿用既有 `warningLevel` 模拟等级，不代表真实预警。开场不再强制显示预置的 18 分钟；ETA 与点击分析统一为预测轨迹首次覆盖矿区时间。无可靠结果显示“暂无法估算”。距离保留既有球面边界距离口径。

底图使用项目本地 Natural Earth 影像；配置了 `VITE_TDT_KEY` 时复用天地图。**用户当前没有真实高程地形和矿区模型数据，因此默认仍为椭球地表。** 云体是程序化积云示意，并非雷达实测云顶或物理大气仿真。页面分别显示影像、地形、矿区模型的状态。

旧 Three.js 场景文件仅保留作参考，不再从 v3 页面加载。

### 可选地理资源配置

在取得适用数据后配置 `.env.local`，并重启开发服务：

```dotenv
# 支持 CesiumTerrainProvider 的地形服务根地址；未提供时留空
VITE_TIANJI_TERRAIN_URL=
# JSON 对象：weather.ts 内矿区 ID → 对应 tileset.json 地址
VITE_TIANJI_TILESETS={}
```

只请求明确配置的 HTTP(S) 或同源相对地址，不使用默认 Cesium Ion Token。自有服务是否需要 Key 取决于服务端鉴权；不要在 `VITE_` 变量里放服务端私钥，这些值会进入前端包。跨域服务须允许当前站点访问。

地形在相机降至 1600 km 以下时加载；所选矿区模型在开启「重点资产」且相机降至 850 km 以下时加载。模型必须包含正确的地理定位。切换矿区释放旧模型，远离时隐藏已加载模型，加载失败或超时回退。模型缓存预算 96 MB、溢出预算 24 MB，实际占用由内容决定。未配置资源时页面显示「未接入」，不生成虚构建筑。

## 工程与检查

演示状态与相机取消逻辑在 `cinematicCamera.ts`；Cesium 生命周期和批量渲染在 `cesiumScene.ts`；云团与流动特效在 `stormEffects.ts`；地理资源懒加载在 `geographicResources.ts`。界面继续复用 `index.vue`，新增样式限定于 `.wc-immersive`。

开发模式右下角可展开性能面板：实际渲染 FPS、初始化和飞行耗时、可获取的 JS Heap 及增量、Primitive 和云团单元数量、画质档位、地形/模型加载耗时和模型资源估算。模型资源估算不等于 GPU 总显存。低配置设备限制像素密度、减少云团单元；连续三个飞行采样窗口低于 24 FPS 时降档。按需渲染下静止画面低 FPS 不代表卡顿；没有测得的数据不显示为零。

```sh
npm run type-check
node src/features/tianji-command-v3/commandDemo.check.mjs
```

UI 和真实设备流畅度由用户验收。本次续写未运行测试或浏览器巡检；地形/建筑接口因无数据尚未进行实际接入验收，长期内存稳定性也仍待验证。
