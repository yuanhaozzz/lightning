# 雷暴临近预警指挥舱

独立路由 `/tianji-command`，未改变其他页面。围绕“雷暴在哪里、距矿区多远、正在如何移动”设计。

## 四个模块

- 雷电实时监测：雷达回波范围、近 30 分钟落雷与独立矿区标记。
- 雷电热力图：同一批落雷记录聚合成密度图，隐藏距离和回波图层。
- 雷暴移动轨迹：历史实线与未来 60 分钟预测虚线，时间标记随回放变化。
- 雷暴临近预警：自动进入矿区视角，显示扫描扇面、距离圈及当前等级。

全国/矿区、2D/3D、缩放复位、矿区切换、图层控制、回放均可交互。矿区视角可点选落雷查看时间、电流和距矿区距离。

## 多雷暴与动态表达

- 神东矿区演示三片雷暴从西北、东北、东南同时临近。右侧列出 350 km 内每片雷暴，按回波边缘距离从近到远排序，分别显示编号、方向、等级和临近趋势。
- 点选列表或地图编号可独立跟踪。只有选中的雷暴绘制测距线，其余雷暴保留范围、距离标签和预测方向；矿区主卡片始终显示最近雷暴的距离与最高预警，不随跟踪选择降低。
- 冰蓝地图底板、发光边界与弱地理网格，提高地理轮廓辨识度。雷达扫描周期 3 秒，所有轨迹带方向光点，近期落雷记录带位置脉冲。回波内部动画不改变用于测距的边缘几何。
- 默认运行模拟时间，1× 每秒推进 15 秒场景时间；可暂停、拖动或回到当前。页面隐藏时停止推进。系统偏好减少动态效果时默认不自动播放，并停用环境动效。
- 回波、距离、分级与轨迹共用同一场景时间。图层开关、热力图模式、选择切换及卸载均清理相应对象。

**距离口径：**模拟雷达回波边缘至矿区中心的最短距离，采用球面距离；屏幕测距线端点、卡片数字与预警等级使用相同数据。距离圈为球面目的地算法生成，表示预警参考范围，不代表装备探测能力。矿区间没有网络连线。

## 用户指定的演示阈值

| 回波边缘距矿区中心        | 等级     |
| ------------------------- | -------- |
| 大于 200 km               | 常态监测 |
| 大于 150、且不超过 200 km | 四级     |
| 大于 100、且不超过 150 km | 三级     |
| 大于 50、且不超过 100 km  | 二级     |
| 不超过 50 km              | 一级     |

`weather.ts` 提供模拟矿区、雷暴运动和固定落雷记录；`weatherScene.ts` 为 Three.js 渲染；`index.vue` 与 `weather.css` 是交互和界面。使用项目已有中国 GeoJSON，保留全部省域、岛屿、孔洞及边界线。只保留挤出地图底板，不生成虚构地形或工业模型。

所有雷达、落雷及预警业务数据均为模拟，页面持续标注。分级为用户指定的演示规则，不是对外发布的气象预警。此页不模拟 UE5 厂区；后续真实场区场景与实时数据接入可独立实现。

验证：`npm run build`；`node tmp/tianji-weather-check.mjs`（阈值边界、球面距离圈、测距一致性、临近过程、事件时间窗口）。
