# 青岛省心券 · 原生微信小程序

JS / WXML / WXSS，无第三方依赖、无需 npm 构建。仅访问后端公共 API，不包含联盟密钥、消费者登录、钱包、收款或返现功能。

## 导入与开发

1. 按仓库根 README 启动 API，默认端口 `3018`。
2. 在微信开发者工具中导入本目录。`project.config.json` 的 `touristappid` **只是开发占位值，不是正式小程序 AppID**；登录开发者工具并替换为你已备案小程序的真实 AppID。游客模式不能证明真实账号功能可用。
3. 本地 API 在 `config.js` 默认为 `http://127.0.0.1:3018`。仅本机开发者工具调试时，可临时在“本地设置”允许不校验合法域名；项目默认 `urlCheck: true`，不把跳过检查当成上线方案。
4. 真机不能使用电脑的 `127.0.0.1`。联调及发布需部署可访问的 HTTPS API，在微信公众平台配置 `request` 合法域名，再改 `API_BASE`；恢复/保持域名检查。
5. 默认品牌名 `青岛省心券` 是项目工作名，页面优先使用 `/api/public/config` 的 `siteName`。正式名称须由账号主体确认可用并通过平台审核，不能把代码名称当作已核准名称。

页面：`home` 首页 / 分类 / 搜索，`offer` 优惠详情和领取，`guide` 使用说明 / 隐私 / 客服。全部优惠来自 API，断网和空列表不会回退成伪造优惠。

## 演示、真实跳转与统计

- `mode` 由服务器控制。配置尚未读取成功时默认显示演示标识；演示模式各页顶部固定显示横幅，点击领取只显示提示，不跳转、不生成订单、不提示“领券成功”。未配置真实 AppID 的游客客户端不能加载正式模式配置。
- 真实模式第一次点击调用 `POST /api/public/offers/:id/launch` 准备入口；得到合法 `appId/path` 后显示“打开平台领取”。第二次点击同步调用 `wx.navigateToMiniProgram`。代码不硬编码、不猜测平台目标，也不将“打开成功”当作下单成功。
- 启动参数支持 `channel=qd_office`、URL 编码的 `scene=channel%3Dqd_office`，或 `scene=qd_office`。仅接受 2–32 位小写英文字母、数字、下划线和连字符；其他值不保存。已保存渠道在后续无渠道启动时保留，帮助页可以主动清除。
- 请求领取入口时传 `channelCode`。这只是点击来源记录，不等于平台订单归因；订单仍需后端使用联盟真实订单标识匹配。
- 生产前核实服务端目标来自你实际开通的联盟/推广权限，并确认微信允许该跳转；此工程不代表已通过联盟或微信审批。
