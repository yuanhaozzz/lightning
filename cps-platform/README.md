# 青岛省心券 · CPS 自营入口 v0.1

面向个体工商户运营者的本地可运行起步项目：Vue 3 管理端、Node/Fastify 服务端、原生微信小程序。部署目标是自己的阿里云 Linux 服务器。

**交付边界：** 已实现管理端登录、优惠管理、渠道标记、点击统计、订单人工导入和对账展示、小程序领取流程。当前没有开通或调用真实联盟 API，也没有部署到你的阿里云、上传微信审核。正式模式支持手工录入从官方渠道获得的推广目标，真实跳转与跟单仍需使用你的账户和真机验证。演示模式不产生真实优惠、订单或收益。

## 目录与选型

```text
apps/admin         Vue 3 + TypeScript + Vite 管理界面
apps/api           Fastify + TypeScript + SQLite（Node 内置 node:sqlite）
apps/miniprogram   原生微信小程序，导入开发者工具即可
deploy             Nginx、systemd 示例
docs               接入说明、API 契约、上线核对表
```

Node 24.15+（24.x）和 pnpm 11.25。Node 的 SQLite API 当前为 release candidate，采用同步访问，适合本项目初期单实例、轻量短查询；未做生产容量压测。数据库文件保存在本机，开启 WAL，后续数据量/写入并发增加时应评估迁移 PostgreSQL/MySQL。

2 核 2GB 是本次轻量部署的目标配置，不代表已验证的并发能力。管理端在开发机打包，由 Nginx 托管静态文件；服务器只运行一个 API 进程。初期不额外引入 Redis、容器编排和微服务。

## 本地启动

在本目录执行：

```sh
pnpm install
```

将 `apps/api/.env.example` 复制为 `apps/api/.env.local`，设置 `ADMIN_USERNAME` 和至少 12 位的 `ADMIN_PASSWORD`。不要提交真实密码或联盟密钥。保留 `DEMO_MODE=true`。

分别开两个终端：

```sh
pnpm dev:api
pnpm dev:admin
```

- 管理端：`http://127.0.0.1:5178`
- API 健康检查：`http://127.0.0.1:3018/api/health`
- 用 `.env.local` 中设置的管理员账号登录。
- 首次启动创建管理员并哈希存储密码；之后修改 env 不会悄悄覆盖现有密码。
- 只想更换开发测试数据时，请先停服务并保留备份，再自行更换 `DATABASE_PATH`。勿误删正式数据库。

微信开发者工具导入 `apps/miniprogram`。游客 AppID 仅供演示；正式业务需替换成自己的 AppID。默认 API 指向本机，仅供开发者工具；手机真机需可访问的 HTTPS 域名。详见 [小程序 README](apps/miniprogram/README.md)。

## 已实现的业务流程

1. 管理员新建优惠，可保存草稿或上架。
2. 管理员新建渠道，例如 `office_a`。小程序启动参数为 `channel=office_a`。
3. 小程序只展示当前环境的上架优惠，支持分类与搜索。
4. 用户点击领取，服务端记录一次点击意图。演示模式仅提示；正式模式返回已配置的目标 AppID/path。
5. 正式目标通过第二次用户主动点击打开。用户在目标平台付款，本站不收订单款。
6. 管理员从官方后台取得账单后，可按约定 JSON 导入订单。按平台+订单号幂等更新，失败整批回滚。
7. 后台分别显示预估佣金、已结算记录佣金、失效订单。**结算记录不等于银行到账，人工导入不等于平台验真。**

没有消费者钱包、自动返现、多级分销、会员充值，也没有把点击伪造成订单。

## 如何接入真实推广

你目前尚未申请联盟账号，请按 [美团接入说明](docs/meituan-integration.md) 完成官方主体认证、媒体登记和权限申请。已备案的小程序不自动获得联盟API权限。

在没有 API 权限时，可以先手工取得官方小程序推广目标，录入优惠的 `targetAppId` 和 **完整跟单 path**。两者都必须来自官方工具或客服确认；不要使用网上猜测的 AppID，不要用普通 H5 URL 替代 path。

将正式配置设为 `DEMO_MODE=false` 后，本版不会展示演示数据，且禁止创建演示订单。正式上架要求填写有效格式的目标。格式正确不等于权限或路径已验证，仍需真机实际测试。

本地 `channel` 用于点击来源统计；手工目标不会自动改写为上游 `sid`。**在官方转链接口接入前，不能宣称不同渠道的真实订单自动归因成功。**

即使填写 `MEITUAN_APP_KEY/MEITUAN_APP_SECRET`，本版也不会发起联盟 API 请求。当前没有可靠的官方签名算法正文，因此没有套用旧博客的签名实现。

## 人工导入订单格式

管理端订单页支持粘贴或选取 JSON 文件。金额单位为整数分；时间使用 UTC ISO 字符串；`settled` 必须有 `settledAt`；渠道必须提前建立。导入不会发起付款。

```json
{
  "orders": [
    {
      "externalOrderId": "从官方账单取得的订单号",
      "platform": "meituan",
      "status": "valid",
      "orderAmountCents": 2500,
      "commissionCents": 80,
      "channelCode": "direct",
      "orderedAt": "2026-10-18T04:00:00.000Z",
      "settledAt": null
    }
  ]
}
```

样例金额仅说明数据格式。支持 `pending/valid/settled/invalid`。重复导入同一订单更新记录，退款后应同步导入失效或最新状态。当前简化订单表不能完整表达多券、多次退款、分次结算；自动联盟接口接入时需要增加子券与结算流水，不能把父订单 `profit` 直接当实收款。

## 验证与部署

```sh
pnpm test
pnpm build
pnpm backup
```

备份命令通过 SQLite backup API 生成一致性快照；不要只复制一个正在写入的 `.sqlite` 文件并遗漏 WAL。请将备份另存服务器之外，并实际演练恢复。

部署步骤见 [阿里云部署说明](docs/deployment.md)。微信名称、备案信息、类目、合法域名、隐私配置及真机验收见 [上线核对表](docs/wechat-launch.md)。
