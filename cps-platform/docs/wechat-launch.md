# 微信小程序上线核对表

核对日期：2026-10-18。适用当前项目：个体工商户已有备案微信小程序，准备自建优惠入口，尚未开通联盟账号。

**目前是本地源码交付，不是已上线、已通过微信审核或已获联盟授权的产品。微信开发者工具编译、微信真机和真实订单验证均尚未完成。** `青岛省心券` 仅作工作名称，正式名称以你现有账号及平台核准结果为准。

## 1. 名称、主体、备案与类目

- [ ] 登录 [微信公众平台](https://mp.weixin.qq.com/)，记录现有小程序 AppID、主体名称、主体类型、现有名称、认证状态、备案状态与服务类目。
- [ ] 确认现有 AppID 仍由你的个体工商户主体持有。不要为了演示新建账号或自行变更主体。
- [ ] 如更名为“青岛省心券”，先在后台核验名称可用性、主体可执行的更名流程、所需材料与命名规范；代码中设置 `siteName` 不等于后台更名或名称获批。不声称该名称已可注册，不预估更名次数或审核周期。
- [ ] 逐项对照实际功能：优惠信息展示、联盟推广跳转、点击来源统计、客服；在后台选择与功能相符且对本主体开放的类目，按要求准备资质。**个体工商户主体不代表所有服务类目都可开通；本项目不替你猜定某个类目。** 若增加平台交易、商户入驻、电影票、酒店或交通业务，应重新核对，不能照搬当前类目。
- [ ] 已备案也应核对“主办者信息、应用名称、服务内容”等是否与即将发布版本一致。涉及备案信息变化的，按微信后台备案变更流程提交、完成相关核验；不要把“以前备案过”当作本次更名或业务变更已获覆盖。
- [ ] 名称、简介、截图和实际功能应一致。简介可据实描述：“提供优惠信息及平台领取入口；领取和订单处理由对应平台完成。”不要使用“官方平台”“全网最低”“必得优惠”“七日所有订单计佣”等未经证实表述。

公开依据：工信部的 [APP 备案通知解读](https://www.miit.gov.cn/jgsj/xgj/hlwgl/art/2023/art_564bf0759d7e41d5b4aa8ce4996b9e84.html) 说明备案登记主体、网络资源和业务等信息，由接入服务提供者或分发平台在线提交；[互联网信息服务备案登记表与真实性核验承诺](https://xzca.miit.gov.cn/bsfw/bszn/art/2024/art_5d3cc7f452c04fdd97b6881a20b656f9.html) 覆盖应用名称、类别及信息变化后及时更新。这是一般备案依据，不能替代山东管局或你的微信账号实际处理结果。

微信官方核对入口：[小程序产品文档](https://developers.weixin.qq.com/miniprogram/product/)、[小程序服务类目与资质材料](https://developers.weixin.qq.com/miniprogram/product/material.html)。本次公开抓取未能读取这些微信页面全文；具体名称规则、类目开放范围、备案变更流程仍须以登录后台的当前要求复核，未在本文虚构确定答案。

## 2. 工程、生产 API 与域名

- [ ] 导入 `apps/miniprogram`，把 `project.config.json` 的 `touristappid` 替换为**自己的真实 AppID**。游客 AppID 只用于本地演示；代码也会拒绝使用未配置真实 AppID 的客户端展示正式服务。
- [ ] 部署 API；确认 `/api/health` 正常，先保留服务端 `demo`。
- [ ] 配置有效 HTTPS 证书，设置生产 API 地址。在微信公众平台“开发管理/开发设置”的当前入口配置 `request` 合法域名，随后修改 `apps/miniprogram/config.js` 的 `API_BASE`。
- [ ] 核验生产域名的归属、相关备案要求、HTTPS 证书链、到期时间及平台域名配置限制。程序不依赖外部图片，不需要为了本版本增加图片下载域名。
- [ ] 使用 `https://真实域名`，不要把本机 `127.0.0.1`、HTTP、局域网地址、开发代理或关闭域名检查当作发布配置。真机上的 `127.0.0.1` 是手机本身。
- [ ] 开发者工具“本地设置”若曾临时跳过合法域名校验，提交前恢复校验并再次测试；项目默认 `urlCheck: true`。
- [ ] 生产环境限制后台管理入口，密钥仅保存在服务端环境变量中，不写入小程序、前端包、截图或仓库。小程序只调用公共 API。

官方核对入口：[微信小程序网络能力与服务器域名](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。该官方网页本次抓取受阻；上线前应打开官方文档与后台逐项确认当前 HTTPS、备案、端口、证书及域名限制。

## 3. 联盟入口与跨小程序跳转

- [ ] 先开通实际业务所需的联盟推广权限，核对主体准入、推广渠道登记和可使用的素材/链接。不要从演示数据推断已接通美团或其他平台。
- [ ] 获得你自己推广身份下可核验的承接小程序 AppID 和页面路径，把目标配置到后端；不能从网络猜测目标 AppID、替换别人 PID 或制造推广参数。
- [ ] 核对微信官方 `wx.navigateToMiniProgram` 当前适用范围、基础库、用户触发要求及可能的目标/跳转限制，结合自己的账号权限确认。不要假定“知道目标 AppID 就一定能跳转”，也不要按过往文章硬编码跳转数量限制。
- [ ] 本工程从用户主动点击开始请求 `/launch`，服务端返回真实目标后，用户再次点击“打开平台领取”，才同步调用 `wx.navigateToMiniProgram`；不在页面加载时自动跳转。
- [ ] `demo` 返回只显示提示，既不跳转也不生成订单。“准备入口”“跳转成功”“点击数”均不等于领券成功或成交。
- [ ] 测试同意跳转、用户取消、平台目标失效、无权限/错误 AppID、无网络等路径；失败时保留清晰反馈。后端只返回获准且实际配置的目标。
- [ ] 自己完成一笔允许的测试订单，等待联盟记录及结算，核对推广标识、订单号、归因、订单失效/退款、结算金额；禁止用本地模拟订单充当真实收益证明。
- [ ] 确认全部条件满足后由运营者切换服务端 `live`。前端不能自行解除 demo、创造佣金或启用消费者返现。

官方核对入口：[wx.navigateToMiniProgram](https://developers.weixin.qq.com/miniprogram/dev/api/navigate/wx.navigateToMiniProgram.html)。本次微信文档抓取失败，故本文仅记录实现策略和发布前核验项，不声称已经确认本账号可跳转或已通过平台限制验证。

## 4. 隐私与客服

- [ ] 服务端 `/api/public/config` 填写真实 `siteName`、`supportWechat`、`notice`、`privacyText`。隐私文本需按实际部署补充经营者身份、联系渠道、处理信息种类、用途、保存期限和请求处理方式。
- [ ] 与微信后台“用户隐私保护指引”核对实际行为。本版无需消费者登录，不请求手机号、头像、定位、通讯录；用户主动复制客服微信时才写入剪贴板。
- [ ] 本机保存合法渠道代码，领取请求发送 `channelCode` 用于点击来源统计。说明这不是消费者唯一身份，也不是对真实订单终身绑定；帮助页提供清除本机记录功能。
- [ ] 如服务器记录 IP、访问日志或后续增加 SDK、统计、登录、位置、手机号等，更新隐私文本与平台指引；不能沿用与实际采集不符的“零收集”承诺。
- [ ] 设置能够实际接收反馈的客服渠道；没有配置时页面明确显示未配置，不展示伪造账号。订单、退款由实际下单平台客服处理。
